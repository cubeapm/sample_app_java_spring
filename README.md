# sample_app_java_spring

1. `./mvnw clean install` is used in the context of building and packaging a Java project using Apache Maven.
2. `./mvnw spring-boot:run` is used to start a Spring Boot application using the Maven Wrapper.
3. `docker compose up --build` used to create and start the containers which defined in Docker Compose configuration file, and it rebuilds the container images.
4. Java Spring Boot app will now be available at `http://localhost:8080`.
